# Qubuhub

Qubuhub is a workspace for exploring and documenting software projects, web technologies, decentralized systems, and related research.

## Explore this workspace

The repository contains project notes, development resources, research artifacts, and web content. Individual directories may represent experiments or work in progress; their presence does not imply that an application is complete, deployed, or production-ready.

- Start with the [repository overview](../../README.md) for the current project map and validation notes.
- Read the [engineering rules](../../AGENTS.md) before proposing repository changes.
- Review [CODEX.md](../../CODEX.md) for the extended development workflow.

## Working principles

- Prefer small, reviewable changes backed by reproducible checks.
- Clearly distinguish implemented functionality from proposals and experiments.
- Keep credentials and private information out of source control.
- Treat host-level changes and software installation as explicit, opt-in operations.

## Project status

This page describes the workspace at a high level. For implementation status, build instructions, or release information, consult the specific project directory and its verified documentation. No deployment or production-readiness claim is made by this page.
